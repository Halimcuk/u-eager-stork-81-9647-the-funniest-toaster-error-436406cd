A tiny program that writes one deadpan toaster error message to `/output/entry.txt`: a toaster that has counted every slice it ever toasted against its factory lifetime quota, and on the last one reports its own end in the flat voice of an appliance error code. The line is 63 characters, fixed and deterministic, so every run writes the same bytes.

## Run it

```sh
node main.ts
```

The message is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is not set). Node 22, standard library only, no dependencies.
